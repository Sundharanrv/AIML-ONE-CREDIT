This repository hosts the source code for a **single-page personal portfolio website** created by **Sundharan R V**, an undergraduate student specializing in AI & ML. The site presents featured projects, technical skills, and a concise introduction — deployed on Vercel for public access.

## 🖥️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Sundharanrv/AIML-ONE-CREDIT.git

# Navigate into the directory
cd AIML-ONE-CREDIT

# Open in browser
open index.html
# Or simply double-click index.html in your file explorer
```

> No build tools or server required — it's a pure static website!
